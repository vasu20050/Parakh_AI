## 🌐 What is Parakh AI?

Parakh AI is a **Digital Trust & Evidence Intelligence Platform** — not just another deepfake detector.

Most tools ask: *"Is this AI-generated?"*
Parakh AI asks: *"Can this content, its claims, context, source, and origin actually be trusted?"*

A piece of media may be **authentic** while the claim attached to it is **false** or **misleading**. Parakh AI evaluates both independently and presents the evidence.

### Core Capabilities

| Capability | Description |
|---|---|
| 🖼️ **Media Forensics** | AI-generation detection, manipulation analysis, metadata forensics, face analysis |
| 📝 **Claim Verification** | Extract factual claims and evaluate them against retrieved evidence |
| 🔍 **Source Intelligence** | Analyze publicly available source signals and reliability indicators |
| 🌱 **Origin Tracing** | Find earlier appearances, likely original sources, and related content versions |
| 📊 **Evidence Engine** | Collect, classify, rank, and present evidence — both supporting and contradicting |
| 🎯 **Trust Score** | Multi-dimensional, evidence-weighted scoring across 5 trust dimensions |
| 📋 **Explainable Reports** | Transparent verdict with evidence graph, truth timeline, and methodology disclosure |

## 🚀 Quick Start (100% Free & Open-Source)

### 1. Start Python Backend
```powershell
cd TrueNewsAI
.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --port 8000
```

### 2. Start Frontend Web App
```powershell
cd frontend
npm run dev
```

### 3. Open Web App
Navigate to [http://localhost:3000](http://localhost:3000)
